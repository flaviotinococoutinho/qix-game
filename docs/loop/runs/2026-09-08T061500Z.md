O que mesclou foi **o documento que propõe**, não **a decisão**. Marcá-lo `[x]` porque o arquivo
chegou seria a confusão que este ledger existe para impedir. Voltou a `[ ]`, com o Status citado na
própria linha para que ninguém precise abrir a ADR para descobrir.

E importa que fique aberto: **é o item que fecha a torneira.** Nenhuma execução do loop pode
decidir a própria cadência — só o mantenedor.
